# TTS Player — одна пауза до и после речи, в настройках

**Статус:** реализовано 2026-10-12, ждёт проверки пользователем. Меняет решения спеки
`2026-10-11-tts-player-pause-others-design.md`: 3 с до первого слова и 5 с до продолжения
других плееров, «задержка — постоянная в коде, не настройка».

## Задача

Сказано пользователем 2026-10-12: пауза перед воспроизведением и после него (пока другие
плееры стоят на паузе) одинаковая и задаётся на экране настроек в миллисекундах.

## Решения

Сказано пользователем:
- Тишина перед первым словом (кто-то встал на паузу) и тишина плеера, после которой другие
  продолжают, — одно значение.
- Значение — в настройках, в миллисекундах.

Записано мной, не разобрано:
- По умолчанию 3000 мс: прежняя тишина до речи. Тишина после речи с 5 с стала 3 с: вызов
  инструмента между сообщениями одного хода дольше 3 с теперь разрывает паузу — видео
  продолжится и снова встанет. Нужно дольше — поднять значение в настройках.
- Пределы 0–10000 мс, шаг стрелок 100 мс. 0 — звук сразу после паузы других, продолжение
  сразу после тишины плеера.
- Поле «Пауза до и после речи, мс» на экране настроек — под флажком «Ставить другие плееры
  на паузу, пока говорю», пишется той же кнопкой «Сохранить». Доступно и при снятом флажке:
  значение хранится, действует, когда флажок стоит.
- Новое значение действует с ближайшего таймера; идущий отсчёт не перезапускается.
- Свой текст по-прежнему без тишины до речи.

## Контракты

### (6) settings.json плеера

```
было   {"tail": <целое 1–20>, "autoplay": <true|false>, "pause_others": <true|false>}
стало  {"tail": <целое 1–20>, "autoplay": <true|false>, "pause_others": <true|false>,
        "gap_ms": <целое 0–10000>}
нет ключа → gap_ms = 3000 без строки в журнале; вне пределов или не целое → 3000 и строка
в журнале (как tail); save вне пределов — SettingsError, файл не трогается
```

### (9') Плеер → MPRIS-плееры: что меняется

```
начало     хоть один Pause() прошёл → звук плеера начинается через gap_ms (было 3 с)
конец      плеер замолчал → через gap_ms (было 5 с), если речь не началась снова
```
