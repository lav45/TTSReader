# TTS Player — озвучка молчит, пока диктую в Claude Code

**Статус:** в работе, дизайн обсуждается.

## Задача

Сказано пользователем 2026-10-13: когда он диктует сообщение в Claude Code (удерживает
пробел), а плеер в это время озвучивает ответ, озвучка мешает формулировать мысль. Плеер
должен приостанавливать озвучку, пока диктовка не закончится.

## Решения

Сказано пользователем:
- Озвучку останавливает только диктовка в Claude Code. Звонки, голосовые в браузере и другие
  программы, пишущие с микрофона, плеер не замечает.
- Отпустил пробел — озвучка продолжается с начала прерванного предложения.

Найдено мной (2026-10-13), основание сигнала:
- Хука на диктовку в Claude Code 2.1.296 нет: 33 события хуков, поля о голосовом вводе нет ни
  в одном; нет и в данных строки состояния, OpenTelemetry (`claude_code.*`), переменных
  окружения, файлах. События `tengu_voice_recording_started` / `tengu_voice_recording_completed`
  идут в поток телеметрии `anthropic`, который в API плагинов (`telemetry.log`) доступен только
  встроенным плагинам; пользовательскому — только поток `collector`, где голоса нет.
- Пока пробел удержан, Claude Code держит в PipeWire поток записи (source-output)
  `application.name = "PipeWire ALSA [2.1.296]"`, `node.name = "alsa_capture.2.1.296"` — имя
  исполняемого файла Claude Code (`~/.local/share/claude/versions/<версия>`). Отпустил — поток
  закрывается. Видно в `pactl subscribe` (журнал 2026-10-13 17:12).

## Цепочка

Записано мной, не разобрано: PipeWire (поток записи Claude Code появился / исчез) → плеер
(наблюдатель за микрофоном) → `Player` (приостановить / продолжить озвучку).

## Контракты

Не разобраны.

## Открытые вопросы

- Как отличить поток Claude Code от чужих надёжно: по имени `PipeWire ALSA [<версия>]` или по
  процессу (`application.process.id` → `/proc/<pid>/exe` в `~/.local/share/claude/versions/`)
  — имя меняется с каждой версией.
- Диктовка в несколько заходов (отпустил, подумал, снова зажал): продолжать сразу или после
  тишины — озвучка иначе влезает между заходами.
- Свой текст (экран «озвучить свой текст») — тоже молчит на время диктовки?
- Озвучка не шла, а за время диктовки пришёл новый ответ — начинать после диктовки?
- Что видно в окне, пока озвучка приостановлена диктовкой: кнопка ⏸/▶, строка сообщения.
- Claude Code при запуске режима голоса пробует `arecord` на 150 мс (`arecordProbe`), если нет
  собственного модуля записи: короткий ложный сигнал — проверить, бывает ли он у нас.
